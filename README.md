# Sh4RPyTweaker

Утилита для настройки и оптимизации Windows (WPF, .NET Framework). Поддерживает персонализацию, настройку производительности, конфиденциальность, системные твики, управление процессами, очистку системы и удаление предустановленных UWP-приложений (bloatware).

## Возможности

- **Персонализация** — настройки проводника, рабочего стола и интерфейса Windows
- **Производительность** — отключение визуальных эффектов, служб и схем энергосбережения (powercfg), ускорение работы системы
- **Конфиденциальность** — запрет сбора данных и доступа приложений к системным ресурсам
- **Твики системы** — служебные настройки реестра, многие требуют перезагрузки
- **Процессы** — список процессов с загрузкой CPU/памяти, завершение выбранных. Системные процессы (System, lsass, svchost и т.п.) защищены от завершения
- **Очистка системы** — временные файлы, Prefetch, кэш браузеров, thumbcache, корзина
- **Приложения (UWP)** — список приложений из Microsoft Store, автоматическое выделение bloatware, пакетное удаление
- **Резервные копии** — экспорт изменяемых веток реестра перед применением твиков и их восстановление

Твики применяются выборочно: отметьте галочками нужные и нажмите **«Применить выбранные»**, либо включайте мгновенно переключателем.

## Системные требования

- Windows 10 / Windows 11
- [.NET Framework 4.7.2](https://dotnet.microsoft.com/download/dotnet-framework/net472) (входит в состав Windows 10/11)
- Права администратора (приложение само запрашивает их через UAC)

## Сборка

Требуется Visual Studio 2019 (Workload «Разработка классических приложений .NET») или MSBuild с .NET Framework 4.7.2 targeting pack.

```
MSBuild Tweaker.sln /t:Rebuild /p:Configuration=Release /v:minimal
```

Или откройте `Tweaker.sln` в Visual Studio и соберите конфигурацию Release.

Готовый файл: `Sh4RPyTweaker\bin\Release\Sh4RPyTweaker.exe`.

## Важно

- Перед применением твиков создайте резервную копию (кнопка **«Резервная копия»** в шапке или раздел **«Резервные копии»**).
- Некоторые твики вступают в силу только после перезагрузки (отмечены жёлтым предупреждением).
- Удаление UWP-приложений необратимо без переустановки из Microsoft Store — выбирайте осторожно.
- Твики вносят изменения в реестр и службы Windows; используйте на свой страх и риск.

## Лицензия

Проект распространяется в образовательных целях. Использование на свой риск.
